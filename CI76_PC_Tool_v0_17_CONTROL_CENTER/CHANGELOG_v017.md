# v0.17 — MOTECK CI76 Control Center LAB

## GUI

- 全域 Qt 深藍黑樣式、MOTECK 文字品牌列與控制中心標題。
- 第一頁由淺色表單轉為深色控制卡；參數群組、數值編輯、故障標籤與上下工具列全域統一。
- 第一頁的馬達控制／診斷按鍵拆為兩列，降低窄視窗擠壓。
- 第二頁保留雙儀表，改為指針在左、大電流數字在右，限流目標獨立顯示。
- 移除自訂儀表 Tooltip；一般 Tooltip 套入全域深色樣式。
- 整體預設視窗 1260×840，小視窗仍保留 scroll fallback。

## Logic

- 移除 >2A 額外勾選與 GUI、worker 端授權條件，0.00～8.00 A 可直接操作。
- 保留 UART 寫入 0x06、讀回 0x19 與原來的過載門檻驗證；沒有修改 MCU 韌體。
- 保留頁一手動確認、頁二自動 UART 寫入與分頁切換取消未送出命令的既有機制。
- **未取消舊 FW 的 2 秒馬達控制測試限制**。

## Verification

- Python 原始碼可編譯，所有已調整的單元測試與新 v0.17 靜態測試通過。
- 無 Windows Qt / CI76 板卡的實際畫面與通訊測試，請以 `tools/layout_smoke.py` 驗證 Windows 介面。
