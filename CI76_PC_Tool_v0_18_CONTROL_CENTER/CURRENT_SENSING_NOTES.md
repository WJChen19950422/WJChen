# CI76 電流差異分析（原韌體未修改）

目前條件：PC Tool 約 1.99–2.00A，外接鉤錶約 1.88–1.90A；若同一穩態、同一馬達支路且參考鉤錶可準確量測 PWM 電流，差距約 0.09–0.12A、相對參考讀值約 4.7–6.4%。這不是 UART 換算或 0x10 命令的問題，因為工具忠實顯示 MCU 回報的數值；但**還不能只憑單一測點就認定 ADC 比例係數錯誤**。

## 現有韌體資料路徑

`adc.c/adcHandler`：先進行 16 次零點取樣求兩支路 ADC offset，

```c
adc.ma_cur = ((adc.ma_ol - adc.ma_offset_ol) * 643) >> 4;
adc.mb_cur = ((adc.mb_ol - adc.mb_offset_ol) * 643) >> 4;
m1.cur = adc.mb_cur - adc.ma_cur;
```

換算每 ADC count 約 40.1875mA。`ctl.c/uart_par()`：先低通 `m1.dp_curAvg`，然後 `PCTL.dp_cur = abs(m1.dp_curAvg)/10`（0.01A/LSB），透過 `0x10` 回傳。

## 檢查順序

1. **測量位置**：鉤錶夾在單一 **M+ 或 M− 馬達線**、**DC 量測**，不要同時夾住兩條線，也不要拿供電端 V+ 電流直接對比馬達電流。
2. **儀表**：確認鉤錶在 PWM 波形及 DC 分量下的規格、帶寬、取樣方式、零點歸零與準確度；若可能，用示波器加合適電流探棒或已校正串聯分流器取得穩態參考波形。電流顯示是 MCU 估計/濾波數值，鉤錶可能回報平均、RMS 或不同頻帶結果。
3. **實際比較**：固定電源電壓、負載、方向，記錄相同時間點 PC Tool 與量測儀器的 0A/0.5A/1A/1.5A/2A/3A 多點資料，**不要僅改限流設定當成校正基準**。
4. **區分 offset / gain**：零載附近顯示不為 0，先查 ADC offset；如果每個測點大致呈相同比例，再檢查放大電路、分流電阻公差、ADC Vref 與係數 `643/16`。
5. **改正驗證**：校正可能影響限流及過流保護判斷，修改前應考慮控制路徑 `m1.cur`、實際相電流與限流動作；修改後需重跑正反轉、不同 PWM、空載／負載／過流驗證，避免只針對顯示值做修正而讓保護出錯。

不要把 643 直接乘上單一測點比值就作為量產係數；單一測點無法辨認 offset、比例或量測方式的差異。
