# CI76 PC Tool v0.13 LAB — 電流儀表與 Demo 高速監控

## 變更

- 儀表顯示由「數字壓在指針中央」改為 **左側指針、右側大數字（A）**，標示 MCU 回報估算電流，不是馬達速度 RPM 或實際推力。
- Demo 頁提供「Demo 自動快速監控（目標 50 ms）」勾選，預設開啟；進入 Demo 且已連線後自動啟動。離開 Demo 時**還原第一頁原本的自動監控勾選狀態和輪詢週期**。
- 高速輪詢時，每輪優先查詢電流 `0x10`；位置 `0x11` 約每 100 ms 查詢；馬達狀態 `0x12` 約 500 ms；系統狀態 `0x13`、錯誤旗標 `0x17`、累積時間 `0x14` 約 1 秒。
- 加入「電流實際刷新：約 NN ms」數字，根據 PC **實際接收**每筆電流的間隔計算。它不是韌體 ADC 採樣率或資料新鮮度保證。
- 如果 UART 回覆慢、其他操作佔用通訊、或失聯逾時，輪詢會跳過尚未開始的一輪，**不會把多輪指令堆積送出**。因此 50 ms 是目標值而非保證值。
- 保留 v0.12 雙頁獨立限流操作、Hall/POT、學習、診斷、錯誤旗標、運轉時間、舊韌體 2 秒動作限制與 Log；**不修改 CI76 韌體**。

## 測試方式

1. 開啟 Demo 分頁，確認指針在左、右側能看到放大的 `0.00 A`，沒有文字與指針重疊。
2. 將 CI76 接上 COM Port，讀取全部參數。進入 Demo 後確認「自動監控」開啟且上方週期顯示 50 ms。
3. 開動設備（僅在安全測試台），觀察 Demo 的「電流實際刷新」是否接近 50 ms、數字是否連續更新。若實際 100～150 ms，表示 UART / PC / 韌體等有效速率需要實測；不要將設定 50 ms 誤認為確定達成。
4. 回到第一頁，檢查原本的 100/200/500/1000/1500 ms 選擇及自動監控開關已恢復。
5. 重複檢查兩頁的限流寫入/讀回，不應因為畫面更新加快而變成兩組參數或造成不同步。

## 注意

此版本沒有新增馬達控制或突破安全限制。舊韌體沒有獨立 UART 失聯自動停止機制；PC Tool 不可當成安全停止裝置，必須有外部硬體停止手段。
